# Citation and References

## Citing orthoSynAssign

If you use orthoSynAssign in your research, please cite the methods preprint:

**Preprint:**

> Tsai, C.-H., Pina Paez, C. G., & Stajich, J. E. (2026). orthoSynAssign: refine orthogroups using synteny information. *bioRxiv*. https://doi.org/10.64898/2026.08.10.744007

---

## Related Tools & Dependencies

- [OrthoFinder](https://github.com/davidemms/OrthoFinder) — the orthogroup inference tool whose `Orthogroups.tsv`/`N0.tsv` output orthoSynAssign refines.
- [OrthoRefine](https://github.com/jl02142/OrthoRefine) — the original C++ synteny-refinement tool that orthoSynAssign re-implements and improves upon:
  > Ludwig, J., Mrázek, J. OrthoRefine: automated enhancement of prior ortholog identification via synteny. *BMC Bioinformatics* 25, 163 (2024). https://doi.org/10.1186/s12859-024-05786-7
- [pyGenomeViz](https://github.com/moshi4/pyGenomeViz) — used by `orthosynassign-vis` to render synteny plots.
